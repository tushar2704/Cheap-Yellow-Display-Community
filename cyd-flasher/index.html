Done ✓

Missing driver? 📥 CH340 (Windows) 📥 CP2102 (Mac/Win)
🔧 Flashing not working?
  • Port not showing? Swap cable — many are charge-only with no data lines.
  • Failed to connect? Hold the BOOT button on the board while clicking Install, release once flashing starts.
  • Linux? Run sudo usermod -a -G dialout $USER then log out & back in.
  • Safari / Firefox? Web Serial is Chromium-only. Use Chrome, Edge, Brave or Opera.
  • Manual flash? Download .BIN and run: esptool.py --port /dev/ttyUSB0 write_flash 0x10000 firmware.bin
