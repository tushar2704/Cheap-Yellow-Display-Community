# 🧱 3D Enclosure: CYD 2.8" Flush Wall Mount & Smart Home Bezel

> Low-profile, sleek wall mount bracket for using your 2.8" Cheap Yellow Display as a Home Assistant smart home thermostat or room controller. Designed by [@Makerrdesigns](https://youtube.com/@Makerrdesigns).

---

## 🖨️ 3D Printing Recommendations

| Parameter | Recommended Value |
|---|---|
| **Material** | PETG or ABS (recommended for indoor wall longevity) |
| **Layer Height** | 0.20 mm |
| **Infill** | 20% Gyroid |
| **Perimeters / Walls** | 3 walls |
| **Supports** | None needed |
| **Orientation** | Print face down on textured PEI sheet for premium matte finish |

---

## 🔧 Hardware & Mounting

- **Mounting Method**: 
  - Standard UK / EU / US electrical gang box screw spacing (60mm spacing), or
  - 3M Command heavy-duty damage-free mounting strips.
- **Fasteners**: 4x M2.5 x 6mm countersunk self-tapping screws for securing the CYD PCB.
- **Wiring Channel**: Deep rear cable pass-through for 5V concealed in-wall DC power.
