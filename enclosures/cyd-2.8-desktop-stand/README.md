# 📐 3D Enclosure: CYD 2.8" Desktop Wedge Stand

> An ergonomic, snap-fit desktop wedge stand designed specifically for the 2.8" Cheap Yellow Display (ESP32-2432S028R & ESP32-2432S028C). Designed by [@Makerrdesigns](https://youtube.com/@Makerrdesigns).

---

## 🖨️ 3D Printing Recommendations

| Parameter | Recommended Value |
|---|---|
| **Material** | PLA, PETG, or Matte PLA |
| **Layer Height** | 0.20 mm (0.16 mm for smoother front bezel) |
| **Infill** | 15% – 20% (Gyroid or Grid) |
| **Perimeters / Walls** | 3 walls |
| **Supports** | **None required** (designed with 45° overhangs) |
| **Print Bed Adhesion** | Brim optional (clean PEI sheet recommended) |
| **Print Time** | ~1 hr 45 min on modern high-speed printer |

---

## 🔧 Hardware & Assembly

- **Assembly Type**: 100% Snap-fit (no screws required!)
- **Viewing Angle**: 60° ergonomic viewing angle for desk placement.
- **Port Cutouts**:
  - Precision slot for Micro-USB and USB-C connectors.
  - Flush MicroSD card eject channel.
  - Rear vents for ESP32 WiFi thermal dissipation.
  - Acoustic resonance chamber for the onboard speaker.
