# 🖨️ CYD 2.8" 3D Printer Frame Mount (Bambu / Creality / Prusa)

**License:** Creative Commons CC BY-NC-ND 4.0  
**Target Hardware:** `ESP32-2432S028R` (Resistive) / `ESP32-2432S028C` (Capacitive)

---

## 📖 Overview

This bracket mounts the CYD directly to 2020 or 4040 aluminum extrusion printer frames (Ender-3, Voron, CR-10, Prusa, or top bracket of Bambu Lab series). It provides a sturdy angled view for the **OctoPrint & Klipper 3D Terminal** (`07-octoprint-klipper-terminal`).

---

## 🖨️ 3D Printing Recommendations

| Parameter | Recommended Setting |
| :--- | :--- |
| **Material** | PETG or ABS (recommended for chamber heat resistance) |
| **Layer Height** | 0.20mm |
| **Infill** | 30% Gyroid |
| **Walls** | 4 walls for mechanical rigidity |
| **Hardware** | 1x M4 or M5 T-nut with 10mm bolt for 2020 rail slot |
