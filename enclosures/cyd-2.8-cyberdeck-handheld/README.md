## 📖 Overview

The **CYD 2.8" Handheld Cyberdeck** turns the Cheap Yellow Display into a rugged, portable gaming console, WiFi penetration tester, or outdoor sensor terminal. It features ergonomic palm grips, internal clearance for a 1200–2000mAh flat LiPo battery, and dedicated cutouts for a TP4056 USB-C charging board and slide power switch.

---

## 🖨️ 3D Printing Recommendations

| Parameter | Recommended Setting |
| :--- | :--- |
| **Material** | PLA+, PETG, or ABS |
| **Layer Height** | 0.20mm (Quality) |
| **Infill** | 20% Gyroid or Grid |
| **Perimeters / Walls** | 3 walls |
| **Supports** | None required (designed for flat print bed orientation) |
