# 🎛️ CYD 2.8" Desk Stand with Rotary Knob Cutout

**Target Hardware:** `ESP32-2432S028R` (Resistive) / `ESP32-2432S028C` (Capacitive)

---

## 📖 Overview

An ergonomic 45° angled desktop stand equipped with an integrated front-face cutout for an **EC11 rotary encoder knob**. Ideal for media controllers (Spotify companion), smart thermostats, and lighting faders where physical tactile dial control is desired alongside the touchscreen.

---

## 🖨️ 3D Printing Recommendations

| Parameter | Recommended Setting |
| :--- | :--- |
| **Material** | PLA+, Matte PLA, or PETG |
| **Layer Height** | 0.20mm |
| **Infill** | 20% |
| **Supports** | Minimal support under rotary boss |
