# 📐 3D Enclosure: CYD 3.5" Heavy-Duty Angled Stand Case

> Rugged angled benchtop housing designed for the 3.5" Cheap Yellow Display (ESP32-3248S035R / ESP32-3248S035C). Designed by [@Makerrdesigns](https://youtube.com/@Makerrdesigns).

---

## 🖨️ 3D Printing Recommendations

| Parameter | Recommended Value |
|---|---|
| **Material** | PLA+, PETG, or Carbon Fiber PLA |
| **Layer Height** | 0.20 mm |
| **Infill** | 20% Cubic or Gyroid |
| **Supports** | Organic / Tree supports recommended for rear cable port |
| **Anti-Slip**: | 4x 8mm stick-on silicone bumpons on bottom base |

---

## 🔧 Hardware & Assembly

- **Fasteners**: 4x M3 x 8mm socket head cap screws (screws into brass heat-set M3 threaded inserts, or directly into plastic pilot holes).
- **Viewing Angle**: 45° angle, ideal for electronics workbench instrument monitors, 3D printer OctoPrint / Klipper screens, or CNC controllers.
