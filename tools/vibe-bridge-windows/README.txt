======================================================
  CYD VIBE BRIDGE HUB — WINDOWS (v1.0)
======================================================

A native Windows companion bridge for your Cheap Yellow Display (CYD)
AI Monitors:
  - Project 47: Antigravity Monitor (Port 5047)
  - Project 48: Claude Code Monitor (Port 5048)
  - Project 49: OpenAI Codex Monitor (Port 5049)

------------------------------------------------------
HOW TO RUN:
------------------------------------------------------
1. Double-click 'VibeBridge.exe' (or 'VibeBridge.bat').
2. If Python 3 is not installed, the app will prompt you
   to download it from https://www.python.org/downloads/
   (Make sure to check "Add python.exe to PATH" during install!)
3. In the VibeBridge Hub window:
   - Click "Copy IP" to copy your Windows LAN IP.
   - Paste that IP into BRIDGE_HOST in your CYD's main.cpp.
4. Click "Start All Bridges" to begin streaming metrics to your CYD!
