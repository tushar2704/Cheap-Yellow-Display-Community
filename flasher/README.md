# ⚡ CYD Web Flasher — Browser Firmware Installer

> One-click browser-based firmware flasher for Cheap Yellow Display boards powered by ESP Web Tools.

---

## 🌐 Live Web Flasher
When GitHub Pages is enabled on this repo, visit:
`https://tushar2704.github.io/Cheap-Yellow-Display-Community/flasher/`

---

## 🚀 How it Works
1. Connect your Cheap Yellow Display to your computer using a USB data cable.
2. Open the Web Flasher page in **Google Chrome**, **Microsoft Edge**, or **Opera** (browsers supporting the Web Serial API).
3. Click the **Install** button next to any community project.
4. Select your ESP32's serial port from the browser modal prompt.
5. The firmware is downloaded and flashed directly onto your CYD in ~30 seconds!
