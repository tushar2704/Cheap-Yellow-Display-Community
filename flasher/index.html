⚡ How to Flash

1

Connect via USB

Use a data cable (not charge-only). Supported on Chrome, Edge, Brave, and Opera.

2

Click Install

Choose any firmware card below and click the yellow Install button.

3

Select COM Port

Browser prompts you to pick your device (CH340 or CP2102).

4

Wait ~30 s

Flashing completes automatically. Your CYD reboots into the new firmware.

Missing driver? 📥 CH340 (Windows) 📥 CP2102 (Mac/Win)
🔧 Flashing not working? Try these fixes
  • Port not appearing? Swap to a different USB cable — many cables are charge-only.
  • Failed to connect? Hold the BOOT button on the CYD board while clicking Install, release after the progress bar starts.
  • Linux? Run sudo usermod -a -G dialout $USER then log out and back in.
  • Browser compatibility? Web Serial only works on Chromium browsers (Chrome 89+, Edge, Brave, Opera). Safari and Firefox do not support Web Serial.
  • Manual flash? Download the .BIN and flash with esptool: esptool.py --port /dev/ttyUSB0 write_flash 0x10000 firmware.bin
